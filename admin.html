How unsigned uploads work:

Unsigned upload preset ml_default is linked in js/cloudinary-config.js. Paste your Cloud Name from your Cloudinary console into that file to enable instant image uploads.

Note: Do not paste your API Secret in frontend code. Unsigned uploads only require your Cloud Name and Upload Preset.

Configuration Reference

window.cloudinaryConfig = {
  cloudName: "your-cloud-name",
  uploadPreset: "ml_default",
  folder: "boutique-maryam"
};
